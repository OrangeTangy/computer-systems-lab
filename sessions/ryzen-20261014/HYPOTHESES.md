# Predictions recorded before collection

Wider SIMD should help cache-resident independent loops; large arrays should compress its advantage. Ordered dot can fail to benefit. A two-read/one-write stream should better match AXPY traffic than a read-only proxy, but remains an empirical reference. Random dependent-load latency should rise around reported capacities; exact attribution needs counters. More homogeneous physical-core workers should increase contention, eventually yielding diminishing throughput returns; a plateau is not guaranteed. These are predictions, not measurements.
